# cascivo-tui implementation plan

Design: `docs/superpowers/specs/2026-11-14-cascivo-tui-design.md` (approved). Crate: `crates/cascivo-tui`.
No product code in the planning session; this file is the contract for the build sessions.

## Research findings

**Text.js (anomalyco/textjs, branch `dev`)** — ported / not ported:

| Idea | Decision |
| --- | --- |
| Class-string → style, memoized per (theme, string) | Port. Bounded cache in `ClassCache`; parse is pure so tests need no cache. |
| Negative / `[arbitrary]` / `1/2` fraction values | Port fractions (`w-1/2`) and `[N%]`; skip negatives and `[#hex]` v1 (theme roles only). |
| Per-edge borders (`border-t`, `border-x`) | Port (`Borders` bitflags). |
| Priority-ordered key dispatch, modal trap, `stopPropagation` | Port as `Keymap` layers: modal > focused widget > app > ambient. Tab cycles focus only if nobody consumed it. |
| "Ambient" shortcuts not shown in keyhints | Port (`Binding::ambient()`). |
| Headless harness: fixed grid, `press("ctrl+k")`, `lastFrame`, `cell(x,y)` | Port as `TestApp` (see API). Key-chord string parser shared with keymap. |
| Per-row hash diff, paced redraws | Skip: ratatui diffs buffers; redraw only on msg/tick. |
| Yoga flexbox, `absolute`/`inset`, `z-*`, `overflow-scroll` | Skip v1 (ratatui `Layout` is 1-D constraint solver; overlays via `modal`/`toast` only). |
| Component set (Dialog, Select, Tree, Markdown, Diff, Textarea, CommandPalette, Spinner…) | v1 takes the spec list; `select`, `spinner`, `tree`, `textarea`, `command_palette` go to backlog. |

**Versions (crates.io, 2026-11-14):** `ratatui 0.30.2` (MSRV **1.88**; re-exports `ratatui-core 0.1.2` + `ratatui-widgets 0.3.2`; backend crate `ratatui-crossterm`), `crossterm 0.29.0`. Depend on `ratatui` only, with feature `crossterm_0_29` pinned and `ratatui::crossterm` for events (single crossterm version, no drift).
Workspace `rust-version = "1.85"` < 1.88: the crate sets `rust-version = "1.88"` explicitly (toolchain is pinned 1.97, so CI is unaffected). Document in README.

**ratatui APIs used (verified in 0.30.2 source):** `Layout::{vertical,horizontal}(constraints).flex(Flex).spacing(u16).areas::<N>(rect)`/`.split`; `Constraint::{Length,Min,Max,Percentage,Ratio,Fill}`; `Block::bordered().borders(..).border_type(BorderType::Rounded).padding(..)`; `Paragraph`, `List+ListState`, `Table+TableState`, `Tabs`, `Gauge`, `Sparkline`, `Clear`; `Color::Rgb`; `Terminal<TestBackend>` + `backend().buffer()` + `TestBackend: Display` (plain-text snapshot); `ratatui::{init,restore,run}` (init installs panic hook); filter `KeyEventKind::Press`. `assert_buffer_eq!` is deprecated: compare strings/`Buffer`. Unverified: exact `Paragraph::scroll` arg aliases (use `(u16,u16)` and let the compiler confirm).

## Decisions

1. **Own tree, ratatui render.** `Node` (enum: container with `Style`, or leaf widget) → `layout.rs` maps class styles to `Layout` calls and recursion; widgets implement `Widget` trait of ours that renders into `Buffer`. Flex model = 1-D stacks only (`row`/`col`), `grow`/`w-N`/`h-N`/fractions map to `Constraint`.
2. **Strict class parser.** Unknown token → `ClassError { token, suggestion }` (Levenshtein ≤2 against vocabulary). Builders take `&str` and return `Node`; error is stored in the node and surfaced at first render as `Err(TuiError::Class)`; never silently ignored. `App::view` returns `Node`; runtime shows the error in a red full-screen panel (and `TestApp::render()` returns `Err`).
3. **Theme codegen: checked-in generated Rust + drift test.** `scripts/tui-kit/gen-theme.ts` (Node, same pattern as `scripts/html-kit/gen-rust.ts`, own header `// @generated by scripts/tui-kit/gen-theme.ts — do not edit`) reads `THEME_NAMES` + `packages/themes/src/<t>.css` (light/dark as `light`/`dark`), resolves each role through the `var()` alias chain and converts `oklch()` → sRGB (small in-script converter, no deps; `color-mix`/`from` derived values are NOT used for roles, error if a role does not resolve to a literal). Emits `src/theme_gen.rs`: `pub static THEMES: &[ThemeData]`. Not build.rs: keeps crate publishable without Node, deterministic, reviewable diff. Drift guards: (a) `pnpm tui-kit:check` regenerates and fails on diff (added to `ready`/CI like `html-kit:check`), (b) a Rust test `theme_gen_is_current` that parses the committed file's role table and asserts every theme in `packages/themes/src` has an entry and all 12 roles are present (needs no Node; skips with message when run from a packaged tarball without the repo).
4. **Roles, not raw tokens.** Fixed 14 terminal roles (table below); classes reference roles (`text-muted`, `bg-surface`), never hex. Truecolor default; `Theme::quantize(ColorDepth)` fallback to 256/16 (nearest-role) selected from `COLORTERM`/`NO_COLOR` at runtime start.
5. **MVU runtime.** `trait App { type Msg; fn update(&mut self, msg: Msg) -> Cmd<Msg>; fn view(&self) -> Node; fn on_key(&self, key: Key) -> Option<Msg>; }` plus `run(app)`; focus is runtime state, not app state; widgets declare `focus_id`.
6. **Test helper first-class.** `TestApp::new(app, w, h)`, `.press("ctrl+k")`, `.type_text`, `.render() -> Result<String>`, `.cell(x,y) -> (char, Style)`; snapshots with plain `assert_eq!` against inline expected strings (no insta dependency; deterministic, reviewable).
7. **No new deps beyond** `ratatui` (+`crossterm_0_29`), `unicode-width` (via ratatui; no direct), nothing else. `thiserror` avoided (hand-written `Display`).

### Theme role mapping

| Role | CSS var (first that exists) | Used by |
| --- | --- | --- |
| `bg` | `--cascivo-color-background` | `bg-bg`, screen clear |
| `surface` | `--cascivo-color-surface` | card, input |
| `surface2` | `--cascivo-color-surface-2` (fallback `surface-raised`) | tabs active, modal |
| `border` | `--cascivo-color-border` | `border` |
| `border_strong` | `--cascivo-color-border-strong` | focused border |
| `fg` | `--cascivo-color-foreground` | default text |
| `muted` | `--cascivo-color-text-muted` | `text-muted`, keyhints |
| `accent` | `--cascivo-color-accent` (fallback `primary`) | buttons, focus ring, gauge |
| `accent_fg` | `--cascivo-color-accent-foreground` (`text-on-accent`) | text on accent |
| `success` / `warning` / `danger` / `info` | `--cascivo-color-success` / `-warning` / `-destructive` (`-error`) / `-info` | status, toast, `text-success` |
| `focus` | `--cascivo-color-focus-ring` (fallback `accent`) | focus ring |
| `selection` | `accent` at 25% over `surface` (computed at gen time) | list/table selection bg |

Alpha values (`/60%`) are pre-composited over `bg` at gen time (terminals have no alpha). Radius tokens ignored (rounded = a theme-independent class). `Theme::{by_name, names}`; default `terminal`; env `CASCIVO_THEME` read by `run` only.

## Class vocabulary (fixed; unknown = error)

Units are terminal cells. `N` ∈ 0..=64 unless noted.

| Group | Classes | Maps to |
| --- | --- | --- |
| Direction | `row`, `col` (node kind; not a class on leaf) | `Layout::horizontal/vertical` |
| Gap | `gap-N` | `.spacing(N)` |
| Padding | `p-N`, `px-N`, `py-N`, `pt-N` `pr-N` `pb-N` `pl-N` | `Block::padding` / inner-rect shrink |
| Size | `w-N`, `h-N`, `w-full`, `h-full`, `w-1/2`…(`1/2 1/3 2/3 1/4 3/4`), `min-w-N`, `min-h-N`, `max-w-N`, `max-h-N` | `Length` / `Percentage` / `Ratio` / `Min` / `Max` |
| Grow | `grow` (Fill(1)), `grow-N` (Fill(N), N ≤ 16), `shrink-0` (Length of intrinsic) | `Fill` |
| Align main | `justify-start`, `justify-center`, `justify-end`, `justify-between`, `justify-around`, `justify-evenly` | `Flex` |
| Align cross | `items-start`, `items-center`, `items-end`, `items-stretch` (default) | child rect offset |
| Border | `border`, `border-none`, `border-t/r/b/l/x/y`, `rounded`, `border-double`, `border-thick`, `border-plain` | `Borders`, `BorderType` |
| Border color | `border-<role>` (`border-accent`, `border-muted`, …) | border style |
| Text color | `text-<role>` (`fg muted accent accent_fg success warning danger info`) | `Style::fg` |
| Background | `bg-<role>` (`bg surface surface2 accent selection success warning danger info`) | `Style::bg` |
| Text style | `bold`, `italic`, `underline`, `strike`, `dim`, `reverse` | `Modifier` |
| Text align | `text-left`, `text-center`, `text-right` | `Alignment` |
| Text flow | `truncate`, `wrap`, `nowrap` | `Wrap`, ellipsis |
| Overflow | `scroll-y` (ListState/Paragraph scroll), `clip` (default) | scroll offset |
| Visibility | `hidden` | skipped in layout (never used to hide on a narrow terminal) |
| Variants | `focus:<class>`, `selected:<class>`, `disabled:<class>` (one prefix per token, only on color/modifier/border classes) | state-resolved style |
| Responsive | `narrow:<class>` (width < 80 cols; breakpoints 40/80/120 cols mirror `30/40/64/80rem` rough mapping) | applied at layout time |

Not in v1: `absolute`, `inset-*`, `z-*`, `flex-wrap`, `basis-*`, margins (`m-*`: use `p-*` on parent / `gap`), hex/arbitrary colors, opacity. Error example: `unknown class "bg-primary": did you mean "bg-accent"?`.

## Public API sketch

```rust
use cascivo_tui::prelude::*;

// tree builders (class string first, children second; &str -> ClassString parsed once)
pub fn col(class: &str, children: impl Into<Vec<Node>>) -> Node;
pub fn row(class: &str, children: impl Into<Vec<Node>>) -> Node;
pub fn text(s: impl Into<String>) -> Text;            // leaf; .class("bold text-accent") .bold() .muted()
pub fn spacer() -> Node;                               // grow filler

// Node: leaf widgets + containers; .class(&str) appends classes; .id(&str) sets focus id
impl Node { pub fn class(self, c: &str) -> Self; pub fn id(self, id: &str) -> Self; }

// runtime
pub trait App {
    type Msg: Clone + 'static;
    fn init(&mut self) -> Cmd<Self::Msg> { Cmd::none() }
    fn update(&mut self, msg: Self::Msg) -> Cmd<Self::Msg>;
    fn view(&self) -> Node;
    /// Global bindings (ambient + shown). Widget-local keys are handled by the focused widget first.
    fn keys(&self) -> Keymap<Self::Msg> { Keymap::new() }
}
pub enum Cmd<M> { None, Quit, Msg(M), Batch(Vec<Cmd<M>>) } // no async in v1; Cmd::tick(ms, M) for timers
pub fn run<A: App>(app: A) -> Result<(), TuiError>;            // ratatui::init/restore, Press-only, redraw on msg
pub fn run_with<A: App>(app: A, opts: RunOptions) -> Result<(), TuiError>; // theme, tick

// focus: Tab / Shift-Tab over nodes with .id(); widgets emit via callbacks => Msg
pub struct Focus { /* current: Option<FocusId>; modal trap stack */ }

// keys
pub struct Keymap<M>; impl<M> Keymap<M> {
    pub fn new() -> Self;
    pub fn bind(self, chord: &str, hint: &str, msg: M) -> Self;     // "q", "ctrl+c", "shift+tab", "f1"
    pub fn ambient(self, chord: &str, msg: M) -> Self;              // not shown in keyhints
}

// theme
pub struct Theme; impl Theme { pub fn by_name(n: &str) -> Option<&'static Theme>; pub fn names() -> &'static [&'static str]; }

// test helper
pub struct TestApp<A: App>;
impl<A: App> TestApp<A> {
    pub fn new(app: A, cols: u16, rows: u16) -> Self;
    pub fn theme(self, name: &str) -> Self;
    pub fn press(&mut self, chord: &str) -> &mut Self;      // routes like runtime, then re-renders
    pub fn type_text(&mut self, s: &str) -> &mut Self;
    pub fn render(&mut self) -> Result<String, TuiError>;   // plain text, trailing spaces trimmed per row
    pub fn cell(&mut self, x: u16, y: u16) -> CellView;     // symbol, fg, bg, modifiers
    pub fn app(&self) -> &A;
}
pub fn render_to_string(node: &Node, cols: u16, rows: u16) -> Result<String, TuiError>; // stateless snapshot
```

### Widget list (builders; every one has a doc example that is run as a doctest)

| Widget | Signature | Notes |
| --- | --- | --- |
| `card` | `card(title: &str, class: &str, children) -> Node` | rounded border, surface bg, title on border |
| `text` | `text(s) -> Text` | `.bold() .muted() .success() .class(..)`; wraps per `wrap` |
| `heading` | `heading(s) -> Node` | bold accent, underline rule optional |
| `list` | `list(items: Vec<String>, selected: usize, on_select: impl Fn(usize)->M) -> Node` | j/k/↑/↓, Enter; `.id()` |
| `table` | `table(header: &[&str], rows: Vec<Vec<String>>, widths: &[Col]) -> Node` | `Col::{Fixed(n),Grow(n)}`; selection, `scroll-y` |
| `tabs` | `tabs(titles: &[&str], active: usize, on_change: impl Fn(usize)->M) -> Node` | ←/→ or 1-9 when focused |
| `input` | `input(value: &str, placeholder: &str, on_change: impl Fn(String)->M) -> Node` | single-line, cursor, Backspace/Delete/Home/End, `on_submit` |
| `button` | `button(label: &str, on_press: M) -> Node` | Enter/Space; `variant` via class (`bg-accent`/default) |
| `progress` | `progress(ratio: f64, label: &str) -> Node` | Gauge; clamps 0..=1 |
| `sparkline` | `sparkline(data: &[u64]) -> Node` | Sparkline; `chart` (bars) deferred |
| `toast` | `toast(kind: Kind, msg: &str) -> Node` | rendered by `overlay` in corner; app owns lifetime via `Cmd::tick` |
| `modal` | `modal(title: &str, body: Node, on_close: M) -> Node` | `Clear` + centered rect, traps focus + Esc |
| `statusbar` | `statusbar(left: &str, right: &str) -> Node` | 1 row, `bg-surface2` |
| `keyhints` | `keyhints(&Keymap) -> Node` | non-ambient bindings: `q quit · tab focus` |

Callbacks are `Fn(..) -> M` evaluated at event time; closures stored in the node (`Rc<dyn Fn>`; single-threaded, `Node: !Send`, documented).

## Open risks

1. **MSRV 1.88 vs workspace 1.85** (spec says 1.85): ratatui 0.30.2 forces 1.88; crate overrides `rust-version`; spec constraint needs a one-line amendment.
2. **oklch→sRGB fidelity:** gamut clipping of high-chroma accents (terminal/cyberpunk) shifts hue; the converter must clip chroma not channels. Verify visually on 3 themes.
3. **Derived tokens:** some themes define roles via `oklch(from …)`/`color-mix`; the gen errors loudly, may need per-theme literal fallbacks (surface-2, selection).
4. **Closure-carrying `Node` + `Msg: Clone`** may force `Rc`/lifetime friction; spike in C4/C6 before widgets; fallback is message-value widgets (`on_press: M`) only.
5. **Terminal color depth:** `NO_COLOR` / 16-color quantization can collapse role contrast; keep `bold`/`reverse` cues for focus so state is never color-only (a11y parity with web).
6. **Unverified ratatui details:** `Paragraph::scroll` arg types, default `crossterm` feature version (mitigated by pinning `crossterm_0_29`).
7. **Skill/CI wiring:** a CI Rust job already runs workspace-wide; adding a Node `tui-kit:check` step needs the `docs-freshness`/`ci.yml` lists updated or it never runs.
