# SidebarApp

Full app shell with collapsible side navigation and top header.

## Install

Copy-paste the source (you own and can edit it):

```bash

```

_Copy-paste only — `SidebarApp` is not exported from `@cascivo/react`. Run the command above to own the source, or compose it from the exported primitives (`Flex`, `Grid`, `Heading`, …)._
