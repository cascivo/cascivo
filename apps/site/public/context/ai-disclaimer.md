# AiDisclaimer

**Category:** feedback  
**Description:** A short, quiet note that AI-generated content may be wrong — "AI-generated content may be incorrect"

## When to use

- Under an AI chat composer or answer, telling readers the output can be wrong
- Beside AI-generated summaries, drafts or suggestions that people may act on

## When NOT to use

- Marking a single field or card as AI-generated — use AiBadge
- Warnings the reader must act on — use Alert

## Anti-patterns

### Repeated boilerplate is skimmed past and stops being read

**Bad:** `Repeating the disclaimer under every message in a conversation`  
**Good:** `Show it once, under the composer or at the end of the thread`  
**Why:** Repeated boilerplate is skimmed past and stops being read

## Related components

- **AiBadge** (pairs-with): AiBadge marks which content is AI-generated; the disclaimer says what that means
- **Alert** (alternative): Alert is for messages that need attention or action

## Accessibility rationale

A plain paragraph: read in document order, never a live region, because it is static guidance rather than a status change. The sparkle is aria-hidden; muted text keeps AA contrast on every theme

## Props

| Name       | Type                | Required | Default | Description                                                                |
| ---------- | ------------------- | -------- | ------- | -------------------------------------------------------------------------- |
| `children` | `ReactNode`         | No       | —       | Replaces the default text — e.g. naming the model or what to double-check. |
| `labels`   | `{ text?: string }` | No       | —       | Overrides for the component’s user-visible strings (i18n).                 |

## Tokens

- `--cascivo-color-text-muted`
- `--cascivo-color-ai`
- `--cascivo-text-xs`

## Examples

### Default

```jsx
<AiDisclaimer />
```

### Specific

```jsx
<AiDisclaimer>Summaries are generated by AI. Check figures against the source report.</AiDisclaimer>
```

## Boundaries

| Area      | Level    | Note                                                    |
| --------- | -------- | ------------------------------------------------------- |
| text      | flexible | Replace via children or labels.text                     |
| placement | flexible | Typically under a composer or at the foot of AI content |
