# cascivo-html

Rust library (and `cascivo-html` CLI in `../cascivo-html-cli`) that turns agent-written `.cv` text
into one deterministic, self-contained HTML file styled by real cascivo CSS.

```rust
let html = cascivo_html::render("card \"Hi\"\n", &cascivo_html::Options::default())?;
```

- `render`, `parse`, `check`; `GUIDE` and `guide_for(name)` ship the agent cheat sheet.
- Zero dependencies; the library never reads files (`@brand-file` needs `Options::brand_resolver`).
- `src/catalog_gen.rs`, `src/css_gen.rs`, `src/guide_gen.rs` and `assets/` are generated by
  `pnpm html-kit:generate` (part of `pnpm regen`); do not edit them.
- `examples/*.cv` have byte-compared `.html` snapshots: `UPDATE_SNAPSHOTS=1 cargo test --test examples`.
- Gates: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`.
