# A2UI fixtures

`v0_9/common_types.json` is the A2UI v0.9 common-types schema, copied verbatim and unmodified from
<https://a2ui.org/specification/v0_9/common_types.json> (retrieved 2026-10-20). It lets the catalog tests
compile the generated A2UI catalog offline.
