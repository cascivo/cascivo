# AiBadge

**Category:** display  
**Description:** Small "AI" marker for AI-generated content; with children it opens a toggletip explaining how AI was involved

## When to use

- Marking a field, card, table cell or message whose content an AI produced or suggested
- Giving readers an on-demand explanation of how AI was involved (model, sources, confidence)

## When NOT to use

- Reporting that generation is in progress — use AiStatus
- Generic status or category chips — use Badge or Tag

## Anti-patterns

### An icon or gradient carries no meaning for assistive tech; the badge names the provenance

**Bad:** `A sparkle icon alone next to AI content`  
**Good:** `<AiBadge /> — visible "AI" text and an accessible description`  
**Why:** An icon or gradient carries no meaning for assistive tech; the badge names the provenance

## Related components

- **Toggletip** (contains): The explanation opens in a Toggletip anchored to the badge
- **Badge** (alternative): Badge is the general-purpose chip; AiBadge is reserved for AI provenance
- **AiStatus** (pairs-with): AiStatus reports work in progress; AiBadge marks the finished result

## Accessibility rationale

Provenance is carried by text, never by colour: the static marker shows "AI" and reads "AI-generated"; the interactive one is a button whose accessible name begins with its visible text ("AI Show information", WCAG 2.5.3), opening a Toggletip that is dismissable with Escape. Forced colours keep the border and text as CanvasText

## Props

| Name       | Type                                                        | Required | Default | Description                                                                                                                                                                                                  |
| ---------- | ----------------------------------------------------------- | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `children` | `ReactNode`                                                 | No       | —       | The explanation shown in the toggletip — model, sources, confidence. Omit for a static marker.                                                                                                               |
| `labels`   | `{ text?: string; explain?: string; description?: string }` | No       | —       | Overrides for the component’s user-visible strings (i18n): `text` (the pill, "AI"), `explain` (appended to the trigger’s accessible name), `description` (what a screen reader hears for the static marker). |

## Examples

### Static marker

```jsx
<AiBadge />
```

### With explanation

```jsx
<AiBadge>
  This summary was generated by an AI model from the last 30 days of tickets. Check important
  details.
</AiBadge>
```

## Boundaries

| Area                | Level    | Note                                                                   |
| ------------------- | -------- | ---------------------------------------------------------------------- |
| explanation content | flexible | Any rich content — model name, sources, a link to learn more           |
| pill text           | strict   | Keep it a short AI marker; do not reuse the badge for unrelated labels |
